# SAMA GIS & Data Analytics Portfolio

A single-page professional portfolio for Sama, built with original HTML, CSS, and JavaScript.

## Features

- Arabic and English interface with right-to-left and left-to-right layouts
- Dark and light themes
- Responsive layout for mobile and desktop
- Subtle animated four-point stars and a moving route plane
- GIS, Power BI, Excel, projects, certificates, and contact sections
- Static contact form that opens the visitor's email app

## Build

Run `npm run build` to copy the site and its public files into `dist/`. Netlify deploys the `dist` directory.

The public certificates folder contains the certificate PDFs currently available. The final Excel certificate card remains pending its file.

## Portfolio content

Project summaries and professional details belong to Sama. The site code and visual design in the current version were rebuilt independently.
